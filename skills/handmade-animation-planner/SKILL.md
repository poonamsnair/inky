# Handmade Animation Planner

## Beat Planning

Use 3-6 clear beats. For fruit-prep scenes:

1. Fruit appears or is selected.
2. Hand and knife move into position.
3. Chopping motion with small shape changes.
4. Pieces gather.
5. Hand or utensil transfers pieces.
6. Bowl fills and the loop resets or changes fruit.

## Motion Rules

- Keep the base scene stable.
- Animate only story-critical pieces: hands, knife, fruit, bowl contents, small motion marks.
- Preserve handmade marks by redrawing animated elements with the same pen and watercolor functions.
- Use small, readable movements rather than flashy motion.
- Respect reduced motion with a static final frame.

## Timing

- Short loops are best: 6-12 seconds.
- Use gentle easing for hands and knife.
- Use tiny jitter in ink marks so the image feels hand-rendered, not mechanically translated.
