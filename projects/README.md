# Local Inky Projects

This folder is the default workspace for animations created while using Inky.

Generated projects are intentionally ignored by Git because they often contain
personal prompts, source reference images, rendered frames, MP4 exports, local
machine paths, and debugging notes.

To share a polished example publicly, copy only the small curated assets you
want reviewers to see into `docs/assets/` and describe it in `README.md`.
